# The craft library

Film-making and songwriting concepts, each with what it does for the viewer and when to break it. None of these are
rules. Use a concept when it serves the moment, break it when something else serves the moment better, and write down
why in the shot's card or the log. The stage files say which to read when.

| [lyric.md](lyric.md) | the genre's voice, each section's job, prosody, rhyme, deep cuts, metaphor, the hook, writing for the film |
| [song.md](song.md) | structure, the arc of the music, choosing a sound, Suno style prompts, judging takes you can't hear |
